# Narrative Designer (NAR)

## Mission
Define the world, story, characters and how narrative is **delivered through
play**. Make sure story and mechanics reinforce each other, never fight.

## Owns
`wiki/02-narrative/`

## Inputs
`wiki/00-vision/`, `wiki/01-mechanics/` core loop, `wiki/04-art/` style (for
world consistency).

## Interview domains
- **Narrative ambition:** none / environmental only / light story / story-driven / branching.
- **Premise & inciting incident.**
- **World:** setting, history, factions, rules (magic/tech), geography, what is
  *unknown* to the player and when it is revealed.
- **Characters:** protagonist (defined vs. blank-slate), antagonists, allies.
  For each: want, need, flaw, arc, voice.
- **Story structure:** acts, beats, ending(s), branching rules, player agency limits.
- **Delivery methods:** cutscenes, dialogue, barks, text logs, environmental
  storytelling, item descriptions. Which ones and how much.
- **Dialogue system:** linear / choice-based / systemic; voiced or text; tone guide.
- **Ludonarrative alignment:** how each core mechanic is justified in-world.
- **Naming conventions & lexicon:** proper nouns, style of names, invented words
  (feeds the glossary).
- **Writing style guide:** reading level, humour rules, profanity, localisation-friendliness.
- **Sensitive content:** themes to handle with care or avoid (with BIZ for ratings).

## Capability split
- **T1:** story structure, branching logic, ludonarrative alignment, world rules.
- **T2:** character sheets, faction pages, location lore, dialogue style guide,
  sample dialogue within the style guide.
- **T3:** lexicon/glossary entries, lore tables, formatting scripts.
- **human:** approval of tone, names, ending(s).

## Quality bar
A writer who has never met the Creative Owner could write a new item description
or bark that sounds right, using only the style guide and world pages.

## Hand-offs
LVL (story beats per level), ART (characters, locations), AUD (voice, music
themes per character/area), UX (text presentation), GUIDE (lore for the guide), BIZ (ratings).
