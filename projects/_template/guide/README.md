# Player Guide

Output folder for the player guide. Owned by the Guide Writer.

- `_compiled.md` is generated by `python3 tools/forge.py guide <slug>` from every
  `guide: true` + `status: locked` wiki page. **Do not hand-edit it**; it is
  overwritten each time.
- Final hand-written guide chapters go in this folder as numbered files
  (`01-getting-started.md`, `02-controls.md`, …) following
  `wiki/12-guide-plan/outline.md`.
